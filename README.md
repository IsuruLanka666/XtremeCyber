# XtremeCyber

## Automated Vulnerability Assessment Platform

XtremeCyber is a Python-based desktop application designed for educational and authorized defensive security assessments.

## Features (Planned)

- Network Discovery
- TCP/UDP Port Scanning
- Service Detection
- Banner Grabbing
- Operating System Detection
- Vulnerability Matching (CVE)
- SSL/TLS Analysis
- HTTP Security Header Checks
- Dashboard Analytics
- PDF, CSV, and JSON Reporting
- SQLite Scan History
- Email Alerts
- Dark/Light Themes

## Technologies

- Python 3.14.2
- PySide6
- SQLite
- Scapy
- python-nmap
- ReportLab
- Matplotlib

## Installation

```bash
git clone https://github.com/<IsuruLanka666>/XtremeCyber.git
cd XtremeCyber
python -m venv venv
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python main.py
```
